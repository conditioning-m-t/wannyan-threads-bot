# わんにゃん暮らしの便利帖（@wannyan_pick）の運用ルール

ペット（犬・猫）アカウント専用のルール。全アカウント共通のルールはリポジトリ直下の `CLAUDE.md`。
このアカウントのファイルはすべて `accounts/wannyan/` にある（`data/`・`drafts/`・`products.json`・`reply_rules.md`）。

## アカウント

- 対象：犬・猫と暮らす人（通販でペット用品を買う人）
- 収益：Amazonアソシエイト（プロフィールにPR表記済み）
- 実績：参加型の「我が家のペットの名前 選手権」がいいね253・コメント461で最も伸びた。
  商品だけを紹介する投稿（箇条書きの広告文＋1投稿目にリンク）は表示30〜50回で伸びなかった

## 毎週月曜は週次の手応えレポートも付ける
オーナーには半年後（2027年4月ごろ）の収益目標がある（金額はチャットで確認済み）。ペットアカウントはその第一歩の試験。
月曜の投稿案のあとに、直近7日の数字を `accounts/wannyan/data/insights.json` から集計して短く報告する：
- 投稿ごとの平均表示・最高表示、選手権の表示、商品投稿の表示、コメント数
- フォロワー数の推移（`accounts/wannyan/data/followers.json`、毎日17:53に記録）。返信の返信でのフォロー誘導（2026-10-20開始）の効果も見る
- 判定（下の基準）と、来週変えること1〜3個
- Amazonの売上（注文数・クリック数）は見られないので、オーナーにアソシエイトのレポート画面のスクショを1枚お願いする（数字だけでよい）

判定の基準（目安）：
- 関門1（〜11/2）：1投稿の平均表示1,000回以上、選手権が週1回は1万回以上
- 関門2（〜11月末）：商品投稿経由のAmazon注文が週3件以上、最初の3件（アソシエイト継続条件）をクリア
- 関門2を越えたら「イケる」と判断し、2つ目・3つ目のジャンルの立ち上げ（CLAUDE.md の「新しいアカウントの立ち上げ」）を提案する

**Threadsへ直接投稿しない。** 投稿は GitHub Actions が行う。シークレットには触れない。

## 1日の構成（3枠）

| 時刻 | 中身 |
|---|---|
| 07:00 | 参加型（質問・あるある）またはお役立ち |
| 12:00 | お役立ち、または商品（商品は1日1本まで、週3本程度まで） |
| 21:00 | 参加型。**毎週火・金は「〇〇選手権」**（自分のペットを語れる・写真を貼りたくなるお題）、他の日は二択・もしも・あるある |

投稿回数は1日3回のままにする（2026-10-20に調査：日本の解説は1日2〜3回が最適、1日5回を超えると1投稿あたりの表示が薄まるとの指摘。Meta日本法人は週7回以上を推奨し、表示の約半分は返信のやり取りから生まれるとしている）。
増やすかどうかは週次レポートの数字で判断する。

### トピック（必須）
Metaによると、トピックを付けた投稿のほうが成果が高い。各案に `topic` を1つ付ける（50文字以内、「.」「&」不可）。
- 猫向け：`猫のいる暮らし`／犬向け：`犬のいる暮らし`／犬猫どちらも：`ペットのいる暮らし`
- 付け忘れた場合は自動で `ペットのいる暮らし` になる

全体の比率は「共感・参加型・お役立ち 7：商品 3」を目安にする。

### ガツガツしない収益化とフォロー誘導（オーナーの方針）
- 商品投稿は、その日の参加型・お役立ちの話題とつなげる（例：朝に「お風呂のあと乾かすの大変派？」→ 昼にペットドライボックスや入浴剤）。商品だけが唐突に出ないようにする
- 商品投稿の1投稿目は悩み・場面・問いかけが主役。商品名やスペックは2投稿目に回してもよい
- **フォロー誘導は1日1回、自然な形で入れる**（オーナーの希望）。基本は選手権の日（毎週火・金）の21時のツリー2投稿目で
  「毎週火曜と金曜の21時は、こんな選手権やってます🐾／次のお題のリクエストもコメントで待ってます／見逃したくない人はフォローしといてもらえるとうれしいです」のような予告＋お願い。
  選手権のない日は、お役立ち投稿の2投稿目などに「こういう小ネタを毎日流してます」程度で添える。言い回しは毎回変える
- 選手権の翌朝7時は、たまに「結果発表・ありがとう」投稿にしてよい（例：「昨日の寝相選手権、67件の寝相ありがとう！審査員のツボはねじれ部門でした」）。
  コメントした人の名前や写真は載せない。次回の選手権予告で締める
- 「フォローして」「いいねして」の連呼はしない

## このアカウントだけの書き方ルール

- **自分で飼っている・使った体験談として書かない**（このアカウントは飼い主を名乗らない）。
  「猫飼いさんに聞きたい」「〜って人多くない？」のように問いかけの形にする
- 病気の治療・予防効果をうたわない。健康の話は一般論にとどめる

## 口調と型の手本（人気アカウントとバズ投稿の分析から）

人気アカウントの**型・口調・リズムは真似るが、文章そのものは絶対に写さない**（著作権の問題になり、似た文章の量産はThreadsで低品質と判断される）。

### 口調
- ゆるいタメ口を基本に、ときどき「です・ます」を混ぜる。友達に話しかける距離感（「〜じゃない？」「〜って人いる？」「教えて」）
- 感情を素直に出す（「尊い」「わかる」「笑」）。ただし誇張しすぎない
- 1文に1つの内容。2〜3行ごとに改行し、文字のかたまりを作らない
- **1行目だけで内容と答え方が分かる**ようにする（おすすめ欄では1行目しか読まれない前提）

### 1行目（フック）の型 ─ 毎日ちがう型を使う
1. 当事者呼びかけ：「猫飼いさんに聞きたい」「犬と暮らしてる人、これわかる？」
2. あるある断定：「〇〇してくる猫、絶対わかっててやってる」
3. 選手権宣言：「〇〇選手権、開催します」（最も伸びた型。毎週火・金の21時）
4. 二択：「〇〇派？△△派？」
5. もしも：「もしうちの子が一日だけしゃべれたら、最初に何て言うと思う？」
6. 数字：「冬が来る前に見直したい3つ」（お役立ち。数字は事実の範囲で）
7. 意外性：「実は〇〇って逆効果らしい」（必ず出典のある事実だけ。大げさな1行目と本文がずれると信頼を落とす）
8. 流行りの参加型お題に乗る：例「オスかメスか当ててみて」のように、写真を貼って当ててもらう形

### 本文の組み立て
- あるある型：場面 → そのときの気持ち → 問いかけ
- 結論先出し型：結論 → 理由1〜2行 → 問いかけ
- リスト型（お役立ちだけ）：テーマ → 3つまでの項目 → 「みんなはどうしてる？」
- 1投稿に1トピック。商品投稿以外に商品を混ぜない

### 締め方
- 一言で答えられる問い、選択肢、「写真もぜひ」で終える（写真付きコメントが一番伸びる）
- 「いいねして」「フォローして」の連呼はしない

### 選手権・参加型のネタ帳（使ったら drafts で重複チェック）
名前の由来／寝相／仕事や家事を邪魔された／変顔・ブサかわ／お迎え記念日／子犬・子猫時代と今／
高いおもちゃより段ボール／家の中の定位置／冬のぬくぬくスポット／飼い主の呼ばれ方（あだ名）／
食いしん坊エピソード／病院に行くと分かった瞬間の顔／「うちの子、ここが変」
