# 「ズボラ家事ラボ」を始めるために、田代さんにお願いすること

上から順に1つずつ進めてください。分からないところがあれば、その番号をチャットで教えてください。
**合鍵（トークン）はチャットに貼らないでください。スクリーンショットも送らないでください。**

## 1. Threadsのアカウントを作る

1. Threadsアプリで、新しいアカウントを作ります（ユーザー名の候補：`@zubora_kaji_lab`）
   - 同じスマホで複数のアカウントを切り替えて使うのは、Metaが認めている普通の使い方です
2. プロフィールを設定します
   - 名前：ズボラ家事ラボ
   - 自己紹介：下の「プロフィール文」をそのまま貼ってください（最後の「※PRを含みます」「投稿はAIで作成しています」は消さないでください）
   - アイコン：（ジャンルに合う画像。Canvaで作ることもできます）
3. 終わったら、チャットで「1番できた」と教えてください。ユーザー名が候補と違う場合はその名前も教えてください

### プロフィール文

```
家事をサボりたい人のための研究所🧽
みんなのラク家事を集めて、毎日メモしてます
水・日の21:30は参加型の選手権
※PRを含みます／投稿はAIで作成しています
```

## 2. 開発用アプリにテスターとして追加する

ペットのアカウントで使っているMetaの開発用アプリに、新しいアカウントを追加します。

1. パソコンで Meta for Developers（developers.facebook.com）を開き、ペットで使っているアプリを選びます
2. 左のメニューの「アプリの役割」→「役割」を開き、「Threadsテスター」に新しいアカウント（`@zubora_kaji_lab`）を追加します
3. Threadsアプリで新しいアカウントに切り替え、「設定」→「アカウント」→「ウェブサイトのアクセス許可」→「招待」から、招待を承認します
4. 終わったら「2番できた」と教えてください

## 3. 合鍵（トークン）を発行して、GitHubに登録する

1. Meta for Developers のアプリの画面で、Threads APIの「ユーザートークン生成ツール」を開き、`@zubora_kaji_lab` の「アクセストークンを生成」を押します
2. 表示された合鍵をコピーします（**チャットには貼りません**）
3. ブラウザで GitHub のリポジトリ（conditioning-m-t/wannyan-threads-bot）を開き、
   「Settings（設定）」→ 左のメニューの「Secrets and variables」→「Actions」→ 緑の「New repository secret」を押します
4. 「Name」に次の名前をそのまま入れます：`THREADS_ACCESS_TOKEN_KAJI`
5. 「Secret」にコピーした合鍵を貼り付けて、「Add secret」を押します
6. 終わったら「3番できた」と教えてください。こちらで接続テストを動かし、正しいアカウントにつながるか確かめます

## 4. Amazonアソシエイトに、新しいアカウントを登録サイトとして追加する

1. Amazonアソシエイトのページにログインし、右上のアカウント名 →「アカウント設定」を開きます
2. 「ウェブサイトおよびモバイルアプリの情報を編集」を押します
3. 「ウェブサイト」に `https://www.threads.com/@zubora_kaji_lab` を追加して保存します
4. 終わったら「4番できた」と教えてください

## 5. 商品リンクを作る

候補の商品一覧（`accounts/kaji/商品候補.md`）を見て、使いたい商品のリンクを Amazon のページ上部のバー（SiteStripe）の「テキスト」で作り、
商品名と一緒にチャットに貼ってください。こちらで事実と注意点を調べて登録します。

## 6. 開始

1〜4が終わったら、こちらで自動投稿と自動返信を「稼働中」に切り替えます。
最初の1週間分の案は、開始前にチャットで全文をお見せします。
