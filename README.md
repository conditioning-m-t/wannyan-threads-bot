# Threads 複数アカウント運用の仕組み

ジャンルごとのThreadsアカウントの投稿案づくり・自動投稿・コメントへの自動返信を、1つの仕組みで回します。
最初のアカウントは「わんにゃん暮らしの便利帖」（@wannyan_pick）です。

## 基本方針

- AIが案を作り、承認済みの状態で用意する。止めたい・直したいときだけチャットで伝える（GitHubアプリは使わない）
- 投稿は1日3件まで。商品リンクはツリーの2投稿目に置き、リンクの直後に「 PR」を付ける
- アカウントごとにジャンル・口調・内容をはっきり分ける。似た投稿は量産しない
- 合鍵（トークン）は GitHub のシークレットにだけ保管し、チャット・コード・ログには出さない

## できること

| 機能 | 状態 |
|---|---|
| 毎晩、翌日分の投稿案をチャットに届ける（何も言わなければ自動投稿） | ✅ |
| 時刻になったら自動投稿（アカウントごと） | ✅ |
| コメント・返信の返信への自動返信（判断が要るものは報告） | ✅ |
| 反応データとフォロワー数を毎日記録 | ✅ |
| 投稿案の自動チェック（形式・商品リンク・似すぎ） | ✅ |
| 新しいアカウントの立ち上げ（チャットで「〇〇ジャンルで立ち上げて」） | ✅ |
| 合鍵の自動更新（毎週） | 書き換え用の合鍵（`SECRETS_WRITER_TOKEN`）の登録後に開始 |

## 必要なシークレット

| 名前 | 中身 |
|---|---|
| `THREADS_ACCESS_TOKEN_<アカウント名>` | アカウントごとのThreadsの合鍵（例：`THREADS_ACCESS_TOKEN_WANNYAN`）。ペットは未登録のあいだ `THREADS_ACCESS_TOKEN` を使う |
| `CLAUDE_CODE_OAUTH_TOKEN` | コメント自動返信用（Macで `claude setup-token` を実行して発行） |
| `SECRETS_WRITER_TOKEN` | 合鍵の自動更新用。このリポジトリのシークレットだけを書き換えられる合鍵 |

くわしいルールと構成は `CLAUDE.md` を見てください。
