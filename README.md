# wannyan-threads-bot

Threadsアカウント「わんにゃん暮らしの便利帖」（@wannyan_pick）の投稿を半自動化する仕組みです。

## 基本方針

- AIが下書きを作り、**人が承認したものだけ**を投稿する（全自動投稿はしない）
- 投稿は1日3件まで、間隔は3時間以上空ける
- 商品を紹介する投稿には必ず `#PR` を付け、リンクはツリーの2投稿目に置く
- アクセストークンは GitHub の Secrets にだけ保管し、コードやログには出さない

## 現在できること

| 機能 | 状態 |
|---|---|
| 接続テスト（Actions → 接続テスト → Run workflow） | ✅ |
| 毎晩19:50ごろ、翌日分の投稿案をClaudeアプリで届ける（何も言わなければ自動投稿） | ✅ |
| 7:00 / 12:00 / 21:00 に自動投稿 | ✅ |
| 毎晩19:13に反応データを `data/insights.json` へ保存 | ✅ |
| コメントへの自動返信（1日50件まで・判断が要るものは報告） | ✅（`CLAUDE_CODE_OAUTH_TOKEN` 登録後に開始） |
| アクセストークンの自動更新 | 準備中 |

## 止めたい時だけ言う方式

毎晩19:50ごろ、Claudeアプリに翌日の投稿案が届く。何も返信しなければそのまま自動で投稿される。
止めたい・直したいときだけ「2番やめて」「3番の◯◯を変えて」と返信すると、Claudeが反映する。

## 必要なシークレット

| 名前 | 中身 |
|---|---|
| `THREADS_ACCESS_TOKEN` | Meta for Developers で発行した Threads のアクセストークン |
| `CLAUDE_CODE_OAUTH_TOKEN` | Macで `claude setup-token` を実行して発行したトークン（コメント自動返信用） |
