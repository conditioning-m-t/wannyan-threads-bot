# wannyan-threads-bot

Threadsアカウント「わんにゃん暮らしの便利帖」（@wannyan_pick）の投稿を半自動化する仕組みです。

## 基本方針

- AIが下書きを作り、**人が承認したものだけ**を投稿する（全自動投稿はしない）
- 投稿は1日3件まで、間隔は3時間以上空ける
- 商品を紹介する投稿には必ず `#PR` を付け、リンクはツリーの2投稿目に置く
- アクセストークンは GitHub の Secrets にだけ保管し、コードやログには出さない

## 現在できること

| 機能 | 状態 |
|---|---|
| 接続テスト（Actions → 接続テスト → Run workflow） | ✅ |
| 毎晩19:50ごろ、翌日分の投稿案をClaudeアプリで届ける（承認はチャットで返信） | ✅ |
| チェックが入った案を 7:00 / 12:00 / 21:00 に投稿 | ✅ |
| 毎晩19:13に反応データを `data/insights.json` へ保存 | ✅ |
| コメントへの返信案の作成 → 承認 → 返信 | 準備中（第2段階） |
| アクセストークンの自動更新 | 準備中 |

## 承認のしかた

毎晩19:50ごろ、Claudeアプリに投稿案の通知が届く。開いて「全部OK」「1と3だけ」「2の◯◯を変えて」などと返信すると、Claudeが承認・修正をIssueに反映する。
時刻になると自動で投稿され、Issueにコメントで投稿URLが残る。

時刻を90分過ぎても未承認の案は見送りになります。
