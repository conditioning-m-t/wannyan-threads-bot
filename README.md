# wannyan-threads-bot

Threadsアカウント「わんにゃん暮らしの便利帖」（@wannyan_pick）の投稿を半自動化する仕組みです。

## 基本方針

- AIが下書きを作り、**人が承認したものだけ**を投稿する（全自動投稿はしない）
- 投稿は1日3件まで、間隔は3時間以上空ける
- 商品を紹介する投稿には必ず `#PR` を付け、リンクはツリーの2投稿目に置く
- アクセストークンは GitHub の Secrets にだけ保管し、コードやログには出さない

## 現在できること

| 機能 | 状態 |
|---|---|
| 接続テスト（Actions → 接続テスト → Run workflow） | ✅ |
| 下書き作成 → 承認 → 予約投稿 | 準備中 |
| コメントへの返信案の作成 → 承認 → 返信 | 準備中（第2段階） |

## 必要なシークレット

| 名前 | 中身 |
|---|---|
| `THREADS_ACCESS_TOKEN` | Meta for Developers で発行した Threads のアクセストークン |
