Instagramのアカウントを作る

スマホ

Threadsだけでは作れないので、まずInstagramを作ります。Instagram側には何も投稿しなくて大丈夫です。

  1. Instagramアプリで、右下の自分のアイコンを押す
  2. 左上のユーザー名 → アカウントを追加 → 新しいアカウントを作成
  3. ユーザー名はClaudeが出した候補を入れる。パスワードは手元（パスワードアプリなど）に保存
  4. 名前を直すとき：設定 → アカウントセンター → プロフィール → アカウントを選ぶ → 名前
  5. 念のため非公開に：設定 → アカウントのプライバシー → 非公開アカウントをオン
まちがえやすい点名前に本名を入れない。Instagramの名前の変更は14日間に2回までです。
2

Threadsのプロフィールを作る

スマホ
  1. Threadsアプリで、右下の自分のアイコンを長押し → アカウントを追加
  2. 1で作ったInstagramアカウントを選んで入る（スマホのInstagramにログインしていないと出てきません）
  3. 名前・自己紹介（Claudeが用意した文をそのまま）・アイコンを入れ、プロフィールを公開にする
  4. 興味・関心のタグに、ジャンルの言葉を入れる
終わったらチャットへ 2番できた と、決まったユーザー名
3

Metaの開発用アプリに、テスターとして追加する

PCスマホ
  1. PC Meta for Developers（developers.facebook.com）を開き、右上のマイアプリ → wannyan-bot
  2. 左のメニュー アプリの役割 → 役割 → 右上の青いメンバーを追加
  3. Threadsテスターを選び、新しいユーザー名を入れて送信
  4. スマホ Threadsアプリを新しいアカウントに切り替え → 設定 → その他の設定 → ウェブサイトのアクセス許可 → 招待 → 承認
  5. PC 役割の一覧で、新しいアカウントに「承認待ち」の表示が消えていればOK
終わったらチャットへ 3番できた
4

合鍵（トークン）を発行する

PC
  1. Meta for Developers の wannyan-bot で、左のメニュー ユースケース → Threads APIのカスタマイズ
  2. 左側の設定を押す（「アクセス許可と機能」ではありません）
  3. 下にスクロールしてユーザートークン生成ツールの欄へ
  4. 新しいアカウントの行のアクセストークンを生成 → 許可 → 表示された合鍵をコピー
まちがえやすい点ほかのアカウントの行を押さない。合鍵はチャットに貼らない・スクリーンショットも送らない。画面はすぐ5へ。
5

GitHubに合鍵を登録する

PC
  1. GitHubで conditioning-m-t/wannyan-threads-bot を開く
  2. 上の設定（Settings） → 左のメニュー シークレットと変数（Secrets and variables） → アクション（Actions）
  3. 「リポジトリのシークレット」の緑のボタン新しいリポジトリシークレットを押す（「環境シークレットを管理する」ではありません）
  4. 名前に、Claudeが伝える名前をそのまま入れる
    THREADS_ACCESS_TOKEN_＜アカウント名を大文字＞
    例：家事なら THREADS_ACCESS_TOKEN_KAJI
  5. 秘密（Secret）の欄に、4でコピーした合鍵を貼る → シークレットを追加
終わったらチャットへ 5番できた → Claudeが接続テストをして結果を報告します
6

Amazonアソシエイトに登録サイトとトラッキングIDを追加する

PC
  1. Amazonアソシエイト・セントラル（affiliate.amazon.co.jp）に、いつものアカウントでログイン
  2. 右上のお名前にマウスを乗せる → アカウント設定 → ウェブサイトおよびモバイルアプリの情報を編集
  3. ウェブサイトの欄に、新しいアカウントのアドレスを入れて追加 → 最後まで進めて保存
    https://www.threads.com/@＜ユーザー名＞
  4. 右上のお名前 → トラッキングIDの管理 → 黄色のトラッキングIDを追加する → 名前を入れて作成（最後の「-22」は自動）
終わったらチャットへ 6番できた と、できたトラッキングID

リンクの作り方

PCチャット
  1. Claudeが出した検索リンクを開き、指定の商品の商品ページを開く
  2. 画面のいちばん上の帯（SiteStripe）の黄色いリンク生成
  3. 右側の問い合わせ番号（追跡番号）を、そのアカウントのトラッキングIDに切り替える（下の表）
  4. リンク形式はショートのまま → アフィリエイトリンクをコピー
  5. 商品ページのスクリーンショットと、リンクを同じ順番でチャットに貼る
まちがえやすい点追跡番号が前のアカウントのままになっていることがあります。スクリーンショットは、右側の「お届け先」（お名前・郵便番号）を隠すか切り取ってください。自分のリンクから自分で買うのは規約違反です。

Cふだんの作業

いつやることチャットに送る言葉の例
毎晩18:17ごろ翌日の投稿案の報告を見る。そのままでよければ返信はいりません「家事の3番やめて」「ペットの2番の◯◯を変えて」
いつでもアカウントごと止める・再開する「家事、全部止めて」「家事、再開して」
毎週月曜Amazonアソシエイトのレポート画面のスクリーンショット（数字だけ）スクリーンショットを貼るだけ
12月中旬までに1回合鍵の自動更新の登録（その時に1手ずつ案内します）「合鍵の自動更新をやりたい」

D守ること

  • 合鍵（トークン）・パスワードはチャットに貼らない。スクリーンショットも送らない
  • 個人情報（お名前・住所・郵便番号・メール・電話番号）は、スクリーンショットで隠す
  • 自分のリンクから自分で買わない（Amazonアソシエイトの規約違反）
  • いいね・他人の投稿へのコメントの自動化はしない（アカウント停止の危険）。手動ならOK
